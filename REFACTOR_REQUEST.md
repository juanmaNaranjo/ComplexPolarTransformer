Realiza una auditoría técnica y científica completa del proyecto, analizando absolutamente todo el código, arquitectura, geometría molecular, dominio complejo, representación polar, pipeline de entrenamiento, inferencia y eficiencia computacional. El objetivo es refactorizar profundamente el código para mejorar estructura, modularidad, estabilidad, rendimiento y mantenibilidad, además de rediseñar el modelo para reducir agresivamente el MAE actual (~0.9) hacia valores cercanos o inferiores a 0.5 manteniendo coherencia con la tesis: un Transformer complejo con representación polar físicamente interpretable. Debes identificar cuellos de botella, errores matemáticos, problemas geométricos, pérdida de información angular, destrucción de fase, operaciones redundantes, ineficiencias CUDA/GPU, problemas de overfitting/underfitting y componentes decorativos o inconsistentes con la hipótesis científica. Propón mejoras inspiradas en modelos como DimeNet++, ViSNet, PaiNN, TensorNet, MGNN, NequIP, Allegro, PoCA y Phaseper, manteniendo el dominio complejo y la representación polar como núcleo del proyecto. Debes proponer una nueva arquitectura V2/V3 más eficiente, estable y expresiva, con mejor modelado radial-angular, mejor preservación de fase y orientación molecular, mejores mecanismos de attention y pooling, mejor representación química y mejores estrategias de entrenamiento y optimización, explicando el impacto esperado de cada mejora sobre MAE, RMSE, R², generalización y eficiencia computacional.
